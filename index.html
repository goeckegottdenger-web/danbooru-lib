添加画师
直接填画师 Tag（不要加 artist: 前缀），也可以直接粘贴 Danbooru 画师搜索网址，保存时会自动提取。
在 Danbooru 长按图片选择「复制图片地址」（以 .jpg / .png / .webp 结尾的 cdn.donmai.us 链接）粘贴到第一行；第二行原帖链接选填（填了点击跳原帖，不填点击放大看图）。
设置与代理配置
填入你的 Worker 代理前缀（末尾带 /?url=，或包含 {url} 占位符）。填好后即可在「自动获取」模式下直接拉取 Danbooru 作品。
如果你的网络无法直连 cdn.donmai.us 导致图片裂开，勾选此项可让图片一并走 Worker 代理加载（仅对 Danbooru / Safebooru 图片生效）。
Danbooru 匿名 API 最多支持 2 个 Tag 条件，以上选项均已适配该限制。
